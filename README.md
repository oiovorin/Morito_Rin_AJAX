# 🎧 AJAX Dynamic Content

Welcome to my **AJAX Dynamic Content** project!  
This assignment builds on the previous Earbuds Promotional Page and focuses on making the page fully **dynamic** using **AJAX, SASS, template elements, and the Fetch API**.

This project uses an API (provided in class) to load material information about the earbuds and updates the view as the user interacts with the hotspots.  
The goal is to create an **interactive product experience** using modern JavaScript techniques. 🚀

---

## 🌐 Project Overview

This project is inspired by real product websites and includes an **imaginary earbud model designed in Cinema 4D**.

In this assignment, I focused on combining **design, animation, and dynamic data loading** to enhance the user experience.

Using **AJAX and the Fetch API**, the page:

- Loads material data on page load  
- Updates the UI when the user interacts with hotspots  
- Responds gracefully to loading and error states  
- Adjusts layout based on device size (mobile/tablet/desktop)

---

## 🛠️ Technologies Used

- HTML5  
- SASS / SCSS  
- JavaScript (ES6)  
- Fetch API (AJAX)  
- HTML Template Element  
- Responsive Design  

---

## 🔄 AJAX Features

- Fetches **JSON material data** from the API on page load  
- Includes separate handlers for:  
  - ✔️ Loading  
  - ✔️ Success  
  - ✔️ Error  
- Displays a **loading spinner** while data is being retrieved  
- Dynamically builds UI using the `<template>` element  
- Updates material information when **hotspots** are clicked  

---

## 📱 Responsive Behaviour

- **Mobile:**  
  - Hotspot is **hidden**  
  - Static product image is shown  

- **Tablet / Desktop:**  
  - 3D model becomes **visible and interactive**  
  - Static product image is hidden
